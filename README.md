# Jardin Agro — Haute Fleuristerie

Projet web e-commerce ultra moderne, premium et responsive pour **Jardin Agro**.

## 🚀 Structure & Remplacement des Médias

Pour remplacer les médias fictifs par vos vrais médias, déposez simplement vos fichiers dans les dossiers correspondants en conservant les noms indiqués :

### Vidéos (`/assets/videos/`)
* `video-accueil.mp4` : Vidéo d'arrière-plan de la Hero Section (format MP4 HD).

### Images (`/assets/images/`)
* **Hero / Général** : `hero.jpg`, `livraison.jpg`
* **Produits** : `rose-rouge.jpg`, `bouquet-elegance.jpg`, `lys-blanc.jpg`
* **Catégories** : `mariage.jpg`, `anniversaire.jpg`
* **Instagram / Clients** : `instagram1.jpg`, `client1.jpg`

## 🛒 Fonctionnalités Panier & WhatsApp

* Le panier stocke les articles dans le `localStorage` du navigateur.
* La commande se fait en un clic sur **WhatsApp** avec un message récapitulatif pré-rempli listant l'ensemble des articles, quantités et options sélectionnés.
